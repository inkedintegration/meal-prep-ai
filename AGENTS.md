# Working agreement for any AI agent in this repo

1. Read docs/SPEC.md and docs/DECISIONS.md before proposing changes. Do not re-litigate settled decisions; extend them with evidence if something must change.
2. This is a clean-room project: study open-source meal apps for concepts, never copy their code.
3. Recipes are user-private data with provenance. Never strip attribution. Never republish site prose.
4. Small commits, honest claims. If it is not tested, say so.
5. No em dashes in user-facing copy.
